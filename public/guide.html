Choose an offline dataset

Open Datasets in the header for the Hug tree of life, Upham mammals, dos Reis primates, and Kew release 4.0 plant trees. All are bundled locally. Kew offers order, family and sampled-species sources; these include gymnosperm outgroups. Large trees open as up to 100 collapsed overview groups with every original tip retained. Search the full source in Reduce or Layout, select the taxa needed, and choose a layout. Opening another source requests a backup download when the current canvas has unsaved changes.

The header follows the selected source. Scientific basis and Source & provenance show its release, evidence, limitations and reuse terms. New library trees open without a calibrated scale. Raw dated primate values are preserved without interpreting them as substitution units. Tree exports retain source-specific citations and data notices.

1. Import your tree

Use Open file for a Newick tree (.nwk, .newick, .tree or .txt), a saved PhyloInk project (.json) or a reduction recipe for the current source.

Newick describes the actual connections, not just a list of names. For example, ((A,B),C); supplies a group containing A and B, connected with C. This is an invented example, not a statement about organisms. The tool does not look up or infer missing relationships.

The file is checked before replacing the current project. Finish or discard an outstanding preview before importing. If the current project has unsaved changes, a before-import.treeproject.json backup download is requested before switching. Keep that file; the app has no persistent autosave or cloud storage. A rejected import leaves the current document in place.

After importing, open Scientific basis · Edit below the title. Describe what the supplied connections mean and record the source or your own hierarchy's name/version. Citations describe the data you supplied; no service is contacted. Source text and original IDs stay intact.

2. Search and select

Reduce → Search imported data finds organisms/endpoints and named groups anywhere in the source, including hidden nodes. Select a result to inspect it, then use Reveal or Expand if needed.

Layout → search finds individual source endpoints and adds their exact IDs to your selection. Use a selected clade's source tips for a whole group where that operation is available. Search results have Previous/Next pages; text matching ignores case and treats underscores as spaces.

Original and corrected display names are searchable. Identical names keep separate IDs: a text match does not merge organisms or establish that two records describe the same entity. If a name is absent from the file, import data containing it. Search does not use online databases or synonym resolution.

Explore the complete source

Choose Explore above the editor canvas to inspect the full current input in a separate read-only rectangular, circular or fan view. Zoom reveals original junctions and labels; shaded groups summarize exactly the stated number of source tips. These automatic groups are temporary display summaries, not changes to the saved reduction or new taxa. Spacing is nonmetric.

Inspect relationships opens the same viewer with Scope → Current drawing, starting at the selected identity. It follows the current accepted reduction or active saved structured/artistic graph, including selected taxa, collapsed groups, omitted memberships and original source paths. A saved view keeps its own recorded scientific context; a difference from current metadata is disclosed. Switching to Complete source inspects the original input with its current declared context. No drawing is regenerated.

Solid diamonds identify authored collapsed groups: zoom does not expand them. Dashed shaded regions are temporary viewing summaries. Search covers the complete source in either scope and identifies drawing junctions, tips represented inside groups and omitted tips. A result outside the displayed graph remains identified in the inspector; choose Inspect in complete source to open its exact identity. The inspector retains the represented/full-source/omitted counts and original source-edge paths of drawing connections. Virtual traversal junctions are not original source identities and are not carried between scopes.

Uniform screen-based branches replace the former separate Topology inspection geometry. Viewing does not use artwork page dimensions, line taper, routing or collision avoidance. Numeric internal labels remain verbatim in source fields; they are not assumed to be support values. Tip names take priority on the canvas. Legacy normalized inspection projects open/save with exact stored artwork and pins. Arrange → Make artistic explicitly adopts those coordinates before editing/exporting, without reshaping them.

Scroll to zoom at the pointer, drag to pan, or use the +/− and Home / fit buttons. Click a junction or summary to inspect its exact source ID and unmodified labels, length tokens and annotations. Double-click to focus. Search covers every source identity, including duplicate names on separate results and tips hidden in the editor. Inspect parent junction follows the original traversal path; its visible segments are highlighted. Keyboard arrows pan, +/− zoom, Home fits and Enter focuses selection.

Return with ← Editor to the same artwork, camera, selection, pins, QA and undo state. Explore navigation does not mark the project unsaved. Save and export remain editor actions and use accepted artwork. Explorer camera/detail state is not saved. Changing the source cancels obsolete viewer work.

The viewer supports up to 100,000 nodes within the existing 800-level / 20 MB Newick import limits. It draws at most 1,800 nodes/groups and 160 labels per frame, plus the selected source path. If a visible polytomy exceeds this budget, the complete group remains summarized; zoom or search to reach any sibling. No children are sampled or invented. The status separates source tips covered by displayed groups from tips outside those groups. A summary can extend beyond the viewport.

Classification retains supplied parent links and membership semantics. An unspecified or unrooted source uses a clearly disclosed traversal for inspection; this is not an adaptive unrooted embedding or a new ancestry claim. Branch lengths, dates, numeric internal labels and support annotations are not inferred or reinterpreted.

Try tree interpretation in Learn

Choose Learn above the canvas, then Try six mammals for a short demonstration, or search the current source for 2–16 tips. A small editor selection or active structured view is used when available. Try common ancestors, displayed clade members, and comparing rectangular/circular drawings. Choose a numbered branching point in either drawing or its equivalent dropdown, then Check reasoning or Explain. Rotating a node exchanges whole child subtrees; it does not change relationships or resolve a polytomy.

Ancestry requires a declared phylogenetic basis, known tip entities and a biological root. Classification and unrooted sources do not supply ancestor answers. Gene/sequence ancestry does not establish species ancestry. Feedback distinguishes displayed descendants from omitted members of the full source clade. Spacing is nonmetric and node numbers are practice markers. Use tip codes for long labels and inspect any reported conflicts.

Local activity scenarios → Open scenario / Save scenario opens or downloads a self-contained activity file. Use Adapt / keep this question → Keep question to record the current prompt, pair/node, layout and rotations. Choose a kept question to begin it with cleared answers. Keep an edited question before saving. Up to 12 setups fit in one file; changing the sample clears them. If none are kept, Save records the current setup.

Scenario files include the full source, citations, sample, title, introduction and educator notes. Review source terms before sharing; notes are visible to everyone opening the file. Learner answers, progress, editor artwork and images are excluded. Source hashes, identities, metadata and question setups are checked before replacing practice state. Opening a scenario makes no external requests and leaves the editor document intact.

← Editor discards the temporary workspace. Download a scenario to retain its setups; there is no saved learner progress. Artwork, selection, pins, QA, undo and unsaved state stay unchanged. Save and export of accepted artwork remain editor actions. The two adaptable scenarios demonstrate possibilities rather than a course. Inheritance and population labs remain future planning items.

Supply ranks only if known; otherwise leave rank records empty and explain that they are unknown. No biological root is required.

In Layout, choose source tips, name the view and set page dimensions, text, stroke and spacing. Use Preview layout → Use layout, or discard the proposal. Save a separate view to keep alternatives. Layout changes preserve supplied connections and unresolved forks.

4. Refine the drawing

Click a junction or label to inspect its source. Pin geometry that should stay fixed; a conflicting regeneration requires explicit unpinning. Use Undo/Redo for accepted changes. Structured views support constrained adjustments; Create artistic copy enables free junction/label moves and stem waypoints while retaining the original view.

For an organic silhouette, select endpoints and draw a border in Shape. Repeat for another selection and border. Set offsets/variation and direction, then use Fit → Preview automatic fit. Keep or discard it. Shape also accepts a local image with adjustable opacity for manual alignment. These Free arrangement tools are separate from compound artistic copies.

Line width and straight/curved controls belong to the current workspace. Quantitative layouts constrain the coordinate carrying distance; unrooted layouts use straight stems. Geometry bends are not new source nodes.

For crowded cladograms, try Preview readability with a fixed or larger page. Font size and selected tips stay fixed. Click reported problems or Show full drawing to inspect overlaps and overflow.

5. Save and export

Save project downloads the editable project, including accepted views, source, provenance, pins and any editing image. Save before closing the tab. Projects from earlier supported versions preserve their artwork on import.

Export package downloads the active accepted design: labeled/unlabeled SVGs with identical branch artwork, an editable project, exact source/mappings, omissions, QA and Sources & Methods with text/BibTeX references. Each file is listed in an artifact hash manifest. Print SVGs at their stated dimensions; the print sheet provides a 50 mm calibration line.

Checked means the implemented geometry/coverage checks passed. Draft identifies issues, unavailable font measurements or work limits. It does not mean the supplied relationships were authenticated. Drafts can be exported with their findings. Review the actual drawing before using it.

Work limits are tracked separately for shared-junction incidence, stroke and label checks. An incomplete check cannot pass. Historical project checks retain their original profile; current checks and exported QA use the latest profile. While dragging an artistic copy, MOVING · geometry unchecked is shown until release. Release checks and accepts one undoable edit; Escape or pointer cancellation discards the movement.

Tree SVGs omit editing overlays, but the project included in a tree package retains them. Check the rights to your own data/images before sharing projects. Original software is 0BSD; bundled scientific data retain their separate terms. See Sources & licenses.

If something is unavailable

  • Preview cannot start: inspect the displayed reason. Supply the relationship meaning/root or the classification hierarchy information required by that mode.
  • Export is disabled: accept/discard the current preview, regenerate a stale view, or remeasure/regenerate if fonts differ. Stored legacy inspection artwork needs explicit adoption through Arrange → Make artistic. Return from Explore to export accepted editor artwork.
  • An imported file is rejected: check its Newick syntax, source identity or project version. A single Newick tree is supported; a plain list, CSV spreadsheet, image or multi-tree container is not a relationship tree import.
  • A pin prevents a change: unpin it explicitly or save a separate view.
  • A label or branch is outside the page: Show full drawing, enlarge the page or adjust spacing/labels. Text is never silently shrunk.
  • Changes disappeared after closing: reopen your downloaded project or backup. There is no autosave; the browser tab alone is not a saved file.

No accounts, online organism lookup, provider connections, automatic relationship inference, dating/fossil tools or trait analysis.
