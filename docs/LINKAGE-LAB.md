# A06.1 — linkage and recombination

Development verification, 2026-11-17. **Learn → Linkage & recombination** extends temporary practice with one adaptable synthetic test cross, **AB/ab × ab/ab**, initially r = 10%, 100 offspring and seed 1. It is separate from the unchanged independent-assortment Inheritance lab. This finite demonstration is not a course or a continuing content commitment. Other A06 experiments still require explicit selection.

## Model and bounds

`linked-two-locus-v1` represents two diploid autosomal loci, A/a and B/b. Each parent supplies two explicit haplotypes from AB, Ab, aB and ab, written with a slash between homologous chromosome copies. AB/ab and Ab/aB both have unphased genotype AaBb but different phase. Homolog numbering is local to each parent, not a chromosome-map identifier. All 16 ordered haplotype pairs per parent are supported; order within the pair does not change probabilities.

One shared recombination fraction r applies to both parents. The control accepts **0–50 whole percentages**, without rounding/clamping. For parental haplotypes XY/xy, the two parental routes each have probability (1−r)/2; recombinant routes Xy and xY each have r/2. Implementation uses integer weights 100−R, 100−R, R and R over 200, where R is the whole percentage. Duplicate gamete outcomes are aggregated, retaining all four named gametes, including zero-probability outcomes. Only double heterozygotes have distinguishable parental/recombinant marker classes; homozygous markers are explicitly uninformative for that classification.

Independent parental gamete draws yield 16 weighted combination cells over denominator 40,000. These cells need not be equally likely. Unphased genotype probabilities aggregate matching cells into all nine genotypes; complete dominance at each locus gives four phenotype classes, retaining zeros. A_ means AA or Aa; B_ means BB or Bb. The sample also preserves the two actual inherited haplotypes separately as offspring phase. Complete dominance does not increase transmission or specify fitness.

At the default test cross, Parent 1's AB, Ab, aB and ab probabilities are 9/20, 1/20, 1/20 and 9/20. The ab/ab tester produces only ab. Offspring AaBb, Aabb, aaBb and aabb therefore have probabilities 45%, 5%, 5% and 45%. Switching Parent 1 to Ab/aB exchanges common and rare classes. At r = 0%, only parental haplotypes are transmitted. At r = 50%, probabilities match the existing independent-assortment model for every supported parental pair; that does not establish different chromosomes.

Sampling accepts **1–1,000 offspring** and integer seeds **0–4,294,967,295**. All offspring enter genotype, phenotype and parental-gamete counts; only the first 64 phased offspring are displayed. Mulberry32 v1 uses two draws per child and fixed gamete order AB, Ab, aB, ab. Identical settings reproduce a trial; increasing its size retains the earlier prefix. Clicking Sample restarts, rather than advancing a generation. Expected counts may be fractional. Finite observed recombinant proportions can exceed 50%; that does not allow model r above 50%. No inferential rate estimate or linkage test is performed.

Assumptions: equal segregation, symmetric recombination, random fertilization, independent parental draws and complete dominance at each locus. There is no sex-specific recombination, selection, mutation, segregation distortion, epistasis, penetrance variation, environment, multigeneration breeding or empirical inference. r is not a crossover count, physical distance or map-distance estimate. The original native SVG is a schematic of phase; marker spacing has no metric meaning. No external artwork or organism data are used.

## Workflow and reuse

Choose phased homologs and r, predict Parent 1's probability of an ab gamete, then Check reasoning or Explain cross. Inspect gamete classes/probabilities, select a weighted combination cell to trace inheritance, and compare a seeded sample. Changing parents/r clears results and feedback; invalid settings hide prior results rather than reusing a stale valid cross. Sample-size/seed changes clear the previous trial. Module switching retains each module's own practice. Returning to the editor resets linkage practice and leaves source/artwork/pins/QA/undo/unsaved state untouched. Labs work independently of the tree's rooting availability.

**Create worksheet** captures only validated educator phases/r, sample size and seed. It reconstructs the phase schematic and optionally regenerates complete offspring counts. Separate student and teacher packages retain the existing A05 context/manifest conventions. Teacher files add exact gamete/genotype references and adaptation reasoning; student files exclude those references, educator notes and authoring records. Neither copies learner predictions, feedback, progress, sample DOM or artwork. Disabling data omits finite count tables while retaining the phase diagram and setup. Context/authoring records are not importable scenarios; project V4 and tree-scenario V1 are unchanged. See [worksheet workflow](WORKSHEETS.md).

The [education companion](https://github.com/EliVHD/phyloink-education/tree/codex/linkage-walkthrough/labs/linkage) contains one test-cross configuration, handout and adaptation notes. Authoritative usage and Teacher's Guides remain here. Change phase, r or sample size to adapt the same example; no further lesson collection is required.
