# PhyloInk 0.1.2-dev.0 — unreleased development notes

**PhyloInk — Phylogenetic Tree Editor & Illustrator**, formerly Clade Studio.

This working build is not a published release and does not replace Clade Studio 0.1.1 or its tagged downloads. The project remains a maintenance prerelease with no ongoing support or update schedule promised.

## Naming and compatibility

- New export ZIPs and locally generated browser/source archives use `phyloink-` names.
- Existing `.treeproject.json` files and V1–V4 project migration remain supported.
- Project format tags, build/manifest discriminators and method/component IDs remain stable compatibility identifiers.
- Original scientific inputs, stored provenance and historical fixtures are preserved.
- The Teacher's Guide is included offline and generated from its canonical Markdown; usage instructions remain a separate guide.
- Adaptable examples and additional Newick sources live in the companion education repository, with no recurring lesson schedule promised.

See [migration notes](../docs/MIGRATION.md), [usage guide](../public/guide.html) and [redistribution records](../REDISTRIBUTION.md).

## Local packages

`npm run release` builds, tests and creates `phyloink-0.1.2-dev.0-browser.zip` and `phyloink-0.1.2-dev.0-source.zip` with checksums under `outputs/releases/`. It does not upload files, create tags or publish a release. Serve the browser archive over local HTTP. The source archive requires the documented Node.js and npm setup.

## Known limits

Layouts and fitting may require manual correction. Geometry checks do not authenticate biological claims. Projects require manual saving. Future Learn, inheritance and population labs are planning items, not implemented features.
