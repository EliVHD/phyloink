## Model and bounds

`neutral-bottleneck-recovery-v1` tracks integer allele-copy counts at one diploid autosomal A/a locus. Generation 0 supplies initial N and A copies, not individual genotypes. The size schedule is initial N before the first small generation, bottleneck N for exactly the configured duration, then a one-step return to initial N. At least one recovered generation must be recorded. The constant-size condition has the same initial frequency and keeps initial N throughout.

For target generation t, sample A_t from Binomial(2N_t, A_(t−1)/(2N_(t−1))). This is reproductive gene-copy sampling with replacement, not an instantaneous mortality cull or a sample of surviving individuals. The previous size supplies the frequency denominator; the target size supplies the count total. Missing alleles remain absent. Fixation remains frequency 1 even when the number of fixed A copies changes with N. Locus loss/fixation is not species extinction.

Bounds: **initial/recovered N 3–500; bottleneck N 2 to initial N minus 1; 2–100 generations; 1–4 trials per condition** (at most eight paths). The first small generation is an integer at least 1; duration is a positive integer; their sum is the recovery generation and must not exceed the horizon. Initial A copies are integers 0–2N; seed is an integer 0–4,294,967,295. Invalid values reject without rounding, clamping or stale results. All generations are retained, with at most **808 condition/trial/generation records** and **800,000 Bernoulli draws** before absorbing-boundary shortcuts. The largest supported strict-reduction schedule actually has 799,992 potential draws.

Mulberry32 v1 streams use `(masterSeed + index*0x9e3779b9) modulo 2^32` for bottleneck trials and an additional `0x85ebca6b` offset for constant-size trials, with zero-based index. The control directly reuses the reviewed neutral constant-size implementation with that offset. Conditions have separate streams; matching trial numbers do not represent the same individuals or guaranteed counterfactual pairs. Repeating identical settings restarts the experiment. Extending only the horizon or trial count retains earlier prefixes when the episode is otherwise unchanged.

The no-drift frequency reference remains p₀. In this neutral model it also equals E[p_t] across independent repetitions; it need not equal the mean of the few displayed traces. H = 2p(1−p) is gene diversity at this one biallelic locus, not a count of heterozygous individuals or a whole-genome diversity estimate. Expected H_t = H₀ multiplied by (1−1/(2N_g)) for each target generation g. This expectation declines; individual H values can rise or fall. Recovery does not reset frequency or H and cannot recreate an absent allele. A few trials cannot reliably estimate loss probabilities or guarantee greater loss than every constant-size trial. Loss by the recorded final generation differs from eventual loss.

Assumptions: neutral alleles, a closed random-mating population, non-overlapping generations and one prescribed temporary size reduction/recovery. No mutation, migration, selection, sex structure, linked loci, individual genotypes, pedigrees, gradual/automatic growth, demographic extinction or empirical inference. Model N is an input, not an estimate of an actual population. No observations are inferred from supplied phylogenies.

## Workflow, plots and worksheets

Set the size schedule and initial A copies, predict the no-drift A frequency after recovery, then check/explain and run both conditions. The native SVG shows scheduled N above complete frequency paths; the shaded interval marks the bottleneck. B/C labels, colours and dash patterns distinguish the trials. Numbered generations are discrete model steps. The generation inspector shows condition-specific N, exact A/a counts, p and H. Percentages/H are rounded for display; integer counts are authoritative. No generations are skipped or resimulated during inspection.

Changing settings clears prior results/predictions; switching Learn modules retains their separate temporary practice. Returning to the editor resets the experiment and leaves exact artwork, source context, selection/camera, pins, QA, undo and unsaved state unchanged. Counts are exact; p/H are derived numerical columns. Disabling data omits plots, tables and CSV while preserving explicit setup/model context.
