# PhyloInk 0.1.2-dev.0

The first **PhyloInk** development prerelease, formerly Clade Studio. It brings together the integrated drawing, exploration and educator-authoring changes since 0.1.1.

The project is **not actively maintained**. Owner development may be sporadic or absent; maintain an independent fork if you need ongoing maintenance. No support response times or update schedule are promised.

## Drawing and exploration

- Explore the complete source or the current accepted drawing in one viewer, preserving authored groups, selected and omitted identities, and original source paths. Viewing geometry is nonmetric.
- Preview five Free arrangement starting shapes, compare with the original, and accept or discard explicitly. Conflicting hard pins reject the proposal; source relationships and hidden artwork are preserved.
- Existing V1–V4 project imports retain supported stored artwork and provenance. Compatibility identifiers and original scientific input bytes remain unchanged. Historical Clade Studio tags and assets retain their original names.

## Teaching and worksheets

- Temporary Learn practice covers common ancestors, displayed clade members and equivalent drawings, including complete-subtree rotations and unresolved forks. Local scenarios save educator setups without learner answers or progress.
- Synthetic labs demonstrate independent inheritance, phased two-locus linkage/recombination, drift and selection, a neutral bottleneck/recovery schedule, and bounded selection comparisons. Explicit assumptions and limits distinguish probabilities, references and finite samples; no traits or population observations are inferred from trees.
- Create editable worksheets with A4/Letter printing, separate student/teacher packages, optional reproducible lab data and complete population CSV records. Teacher references require educator review after custom wording changes.
- The offline usage and Teacher's Guides are included. [PhyloInk education](https://github.com/EliVHD/phyloink-education) supplies a finite showcase of adaptable example projects, handouts, scenarios and lab walkthroughs, including the corrected selection handout. It is not a full course or a continuing content commitment.
- Reviewed wording keeps ancestry comparisons tied to one focal taxon, explicitly directs students to required Learn reference curves, and distinguishes outcomes by a recorded horizon from eventual fixation or loss.

## Downloads and quick start

**Browser ZIP — `phyloink-0.1.2-dev.0-browser.zip`:** extract and serve its folder over local HTTP. With Python 3 installed, run inside the extracted folder:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

**Source ZIP — `phyloink-0.1.2-dev.0-source.zip`:** requires Node.js 22.18 or later and npm. Extract, then run:

```sh
npm ci
npm run dev
```

Open **http://127.0.0.1:4173**. Stop the server with **Ctrl+C**. Direct `file://` application use is unsupported. After installation and building, the app works offline without accounts, backend services or automatic uploads.

Each ZIP includes `release-manifest.json` with file hashes and component licenses. Verify its companion checksum from the download directory:

```sh
sha256sum -c phyloink-0.1.2-dev.0-browser.zip.sha256
sha256sum -c phyloink-0.1.2-dev.0-source.zip.sha256
```

## Verification and limits

Release checks cover strict TypeScript checking, the full regression suite, source checksums, component/dependency review, build identity, exact archive inventories and a clean source-archive installation/build. Edge checks exercise Learn worksheet previews and role separation, the guides and project import; the corrected companion handout was reviewed on all four PDF pages. These checks do not validate the biological truth of supplied sources or replace device-specific print review.

Layouts and fitting can still produce draft contacts, label problems, unavailable font measurements or incomplete checks. Routing is a bounded heuristic. Save projects explicitly before closing; there is no persistent autosave. Learn state is temporary unless explicitly exported as a scenario or worksheet.

Original software is **0BSD**. Bundled scientific data retain their component-specific **CC BY 4.0** or **CC0** terms. Preserve source notices, citations and rights; see the included `REDISTRIBUTION.md` and manifests. Browser/source release ZIPs exclude private material and repository screenshots.
