## Model

The original `wright-fisher-selection-v1` model represents N diploid individuals by 2N allele copies in a closed, constant-size population with random mating and non-overlapping generations. Generation 0 supplies an integer A-copy count, not individual genotypes. For frequency p and q = 1−p, expected random-mating genotype proportions p², 2pq and q² are weighted by positive relative fitnesses wAA, wAa and waa. The next-generation sampling probability is `(p²wAA + pqwAa) / (p²wAA + 2pqwAa + q²waa)`. The next A count is Binomial(2N, probability), implemented as independent Bernoulli draws.

This is an allele-frequency Wright–Fisher approximation, not individual survival, mating/pedigree or measured genotype tracking. Equal fitnesses give neutral sampling. Weights are relative contributions, not absolute survival percentages. Bounds require positive weights, so zero-fitness extinction is excluded. No mutation, migration, linked loci, changing environment, growth or sex structure is modeled. Loss/fixation at the locus is absorbing, including at generation zero. No tree supplies genotypes, observed frequencies or an empirical population-size estimate.

The black reference repeatedly applies the selection recursion without finite sampling. For neutral drift it remains at p0; under selection it is not the expectation of nonlinear finite trajectories or the mean of the plotted trials. A few replicates do not estimate fixation probability or establish selection from an observed increase. At a fixed initial frequency, neutral one-generation variance is p(1−p)/(2N); individual small ensembles need not show the expected ordering of variability.

## Controls, bounds and isolation

Drift starts N = 20, 20 A copies, 40 generations, four trials and seed 1 with equal fitnesses. Selection starts N = 100, 100 A copies and weights 1.2/1.1/1, otherwise the same horizon/trial count/seed. Its first no-drift frequency is 23/44. Predict this pre-sampling frequency with a fraction, decimal or percentage; feedback accepts a frequency tolerance of 0.000001 and carries no saved grade. Run explicitly, then inspect any generation with the slider and exact-count table. Trial numbers and dash patterns accompany colour; small screens can scroll charts/tables locally. Percentages are rounded to four decimal places; allele counts are exact.

Supported bounds are N = 2–500, 1–100 generations, 1–8 trials, integer A copies from 0 to 2N, fitness weights 0.05–2, and an integer seed from 0 to 4,294,967,295. Inputs outside bounds reject rather than silently clamp, round or prune. The worst case has at most 800,000 Bernoulli draws and 808 recorded trial-generation counts, including generation 0. All generations are retained; no animation/thinning/truncation is used. Computation is synchronous and bounded; no new asynchronous worker or stale-result path is introduced.

Mulberry32 v1 streams use trial seed `(masterSeed + trialIndex * 0x9e3779b9) modulo 2^32`, with zero-based trialIndex. Identical settings reproduce all counts. Increasing horizon/trial count preserves existing trial prefixes. Each run restarts rather than advances an earlier run. A different seed can still produce coincident trajectories. Parameter changes clear results/predictions; generation inspection does not resimulate.

The pure model and its UI controller have no tree, host-document, persistence, download or network capability. Switching Learn modules preserves their separate temporary practice and invalidates pending tree replies. Returning to the editor resets/discards population state while preserving exact artwork, source/scientific context, selection, camera, pins, QA, undo and unsaved state.
